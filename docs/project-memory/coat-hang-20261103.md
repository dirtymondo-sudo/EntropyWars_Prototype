mondo 11-03, furious-ish: "Still getting pants clipping through coats. Why is this so prevalent and hard ... Surely this is a known issue". Root cause: Blender coat skirts are baked 90 % to the thigh on their side all the way past the knee, while pack trousers follow thigh + shin; earlier clipping passes only fixed the BIND pose.

Fix (PR #821, three-renderer.js THE COAT HANG, notes character-creator.md "THE COAT HANG", plan row 9 DONE): 16 runtime chains `ewhang_*` per Blender Outer skirt, they FOLLOW the coat's own baked weights (root follows hips), pushed out of tapered leg capsules on the cloth's bind side. His Cowboy 785 -> 64 px. Dropped: fall-to-ground (barrel on wide hips), rest-drape (pulls into leg), maxRoot 85 (hip ledge). Known: cowgirl open-front specks, seat crease on curvy female lab coat. Hair: hairNape moves nape hair weight onto the neck (bowed idle flipped it over the collar).

**Why:** next coat/clothes clipping report should start from this, not re-do bind-pose fixes.
**How to apply:** any new long coat/robe gets this automatically (no sway chains of its own). Pixel-island counts are unreliable on OPEN coats; judge on shaded shots. Harness tips: swiftshader runs ~2 fps so run hangTick 30x per frame to settle; IDS material swap must be re-applied right before each snapshot.
