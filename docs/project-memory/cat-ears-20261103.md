mondo 11-03 asked "Where are the cat ears in the editor? DO we not have any?". There were none (only Meshy Elf ears; the Catgirl's ears are baked into her one-mesh Meshy model).
PR #886 added "Cat ears" (titleknown catgirl ears, CC0) + "Cat ears, round" (jaldmic feline ears, CC-BY, credited) as MakeHuman targets in mpfb_shapes.glb (bake-mpfb.py ANIMAL_SHAPES), shown on OUTFIT > Head > Ears with a strength slider. Only one pair of ears at a time (they swap with the Elf ears). Face resets keep the shaped heads + ears (EW_FACE_RESET_KEYS).
**Why:** the plan doc's 4b guess said the pack ear targets wouldn't reach the top of the head. Renders showed they do.
**How to apply:** bunny / canine / dropped ears are also in animal02 (not baked yet): add one ANIMAL_SHAPES row, run the shapes bake (needs no Blender: stub bpy, see character-creator.md "THE SHAPED EARS"), add the row to the sprites.js `animalEars` group, then `--put` mpfb_shapes.glb + CREDITS.json and update ASSET_MANIFEST. Renders are in /mnt/project-files/cat-ears/. Related [[character-models-plan-doc]] [[creator-tabs-body-slots-20261103]]
