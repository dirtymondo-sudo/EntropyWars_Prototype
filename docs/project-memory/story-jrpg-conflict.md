**Why:** my beats resolved conflict with deals and permission (Nordics free you for a job, Atlanteans let you leave) instead of fights.
**How to apply:** when writing quest beats, every captivity, standoff or "no outsiders" rule ends in a fight or escape the player earns; escalate (field fights -> mini-boss -> scripted loss/capture -> breakout -> chase -> boss); no step contradicts the step before; reread each list for any free pass before posting.
