# THE MODEL WISH LIST — every model the district threads asked for (collected 2026-11-16)

Collected from the NEEDS A MODEL lists that the district threads wrote on 11-16 (their sections in
`docs/notes/areas-complexes.md` and the headers of the district files). Each thread searched MODEL_LIST.md and the
bucket first and found nothing that fits; none of these was generated or stood in for, unless a line says so.
**245 models**, the same thing asked by several districts counted once, most-wanted first inside each group.
Nothing here is approved: Meshy pieces need mondo's OK, and the owner side holds the Meshy key.

Not in this list: Disaster City's own open pieces (the Civic Center's seated statue and blossom tree, already approved)
and MODEL_LIST.md §10 (decor still missing in DOOR HQ).
